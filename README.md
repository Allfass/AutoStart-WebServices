
## Запуск и проверка

1. Убедитесь, что A-запись вашего домена (domain_name) указывает на IP-адрес сервера (необходимо для прохождения валидации Let's Encrypt).
2. Запустите плейбук:
```bash
ansible-playbook playbook.yml
```

3. После выполнения плейбука:
    При переходе на `https://blog.example.com/` откроется сайт-заглушка.
    Панель управления будет доступна по адресу `https://blog.example.com/secret-panel-path/`.
    В панели 3x-ui создайте Inbound с протоколом VLESS, транспортом WebSocket (ws), портом 10000 (xui_xray_ws_port), IP прослушивания 0.0.0.0 (внутри контейнера) и путем `/ray-stream` (/{{ xui_xray_ws_path }}). Безопасность (TLS) в самом Inbound оставляйте выключенной, так как терминацию TLS выполняет Nginx.
